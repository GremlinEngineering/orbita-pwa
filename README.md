# Орбитальная станция Империи · PWA

Веб-клиент станции для вахты, отсеков, карт, радара, рейсов, журнала и офлайн-иллюстраций. Станция отдаёт JSON и иллюстрации из /game-worlds/orbita/. Подписки и оповещения работают внутри приложения.

```sh
python3 tools/build.py
python3 tools/preview.py
```

Сборка создаёт пакет в `dist/orbita/`.
