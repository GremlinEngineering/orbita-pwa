# Орбитальная станция Империи · PWA

Веб-приложение «Орбиты». [Открыть коммуникатор станции](https://games.oopssre.ru/pwa/orbita/)

## Возможности

- Вахта, экипаж, карта палубы, инженерные сети, радар и рейсы.
- Подписки на посты, сигналы и другие события станции с оповещениями внутри приложения.
- Сетевой роман, журнал, радиообмен и скачивание иллюстраций для офлайна.

## Сборка и запуск

Нужен Python 3. Выполните команды из корня репозитория.

```sh
python3 tools/build.py
python3 tools/preview.py
```

Локальный адрес для проверки — `http://127.0.0.1:8766/pwa/orbita/`. JSON и иллюстрации доступны по пути `/game-worlds/orbita/` на сайте станции.

Сборка создаёт пакет в `dist/orbita/`.
